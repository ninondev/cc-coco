Coco 安装和更新

Mac 可以下载「Coco 安装器」，解压后双击打开，再点「安装」。

安装器和桌宠支持 macOS 13 或更高版本，Intel 和 Apple 芯片的 Mac 都能用。

Mac 桌宠已随插件打包，并完成签名和苹果公证，安装时不用再装 Xcode 或编译。

更新插件后，新开一个 Claude Code 会话就会加载新版；桌宠需要更新时，痛包里会提示。

本版改动

小窗没有可用模型时，会带你去「接入 API」；保存 API 密钥并确认费用提示后，就能接着打开小窗。

台词库可以导入自己写的文本文件。照着空白模板填好台词，导入后先预览，确认后启用；不合要求的句子会列出原因。

导入的台词存在本机，不调用模型，也不花 token；可以单独开关、选择语言。小克的导入台词还可以与自带台词混用。

修好了桌宠的版本判断，已经装了较新版本时，不会再提示更新到旧版。

Windows 会话退出后，会清掉对应的状态记录；之后迟到的更新也不会让已经结束的会话重新出现。
