ターミナルの入力欄のすぐ上に、ちっちゃなCocoが住んでいます。

あなたのバグをいちいちのぞきに来ては、ドヤ顔をしてきます。これはClaude Code向けに作られた非公式のファンメイドmodで、デスクトップペット兼コンパニオンです。

> [!NOTE]
> 非公式のファンメイド作品であり、Anthropicとは一切関係なく、公認されたものでもありません。Claude、Claude Code、およびClawdはAnthropicに帰属します。

## インストール

```bash
claude plugin marketplace add ninondev/cc-coco
claude plugin install coco@coco
```

インストールすると、このPCで新しく開くすべてのClaude Codeセッション（ターミナル版、デスクトップ版、VS Code拡張機能）にCocoが現れます。すでに開いているセッションは再起動するだけでOKです。

1つのプロジェクトだけで使いたい場合は`--scope project`、プロジェクトの共有設定には書き込まず自分用だけにする場合は`--scope local`を指定します。インストール後に特定のプロジェクトでCocoをオフにしたい場合は以下を実行してください。

```bash
claude plugin disable coco@coco --scope local
```

なお、デスクトップ版のChat画面やCowork画面、およびクラウドセッションではmodは読み込まれません。デスクトップペットのCoco Petはこの制限を受けず、いつでもあなたのデスクトップ上にいてくれます。

|  | macOS | Windows | Linux |
| --- | --- | --- | --- |
| ターミナル | 実機確認済み | CIテスト済み | CIテスト済み |
| デスクトップ版（Code画面） | 実機確認済み | 未確認 | 未確認 |
| VS Code拡張機能 | 実機確認済み | 未確認 | 未確認 |
| デスクトップペット（Coco Pet） | 実機確認済み | 未確認 | 未確認 |
| Claudeアイコンの変更（初期設定はオフ） | 対応 | 非対応 | 対応（ランチャーを変更） |

Claude Code 2.1.299以降が必要です。バージョンは、ターミナルなら`claude --version`、デスクトップ版ならCode画面で`/status`と入力すると確認できます。LinuxでCoco Petや自分のAPIキーを使うには、Debian 10、Ubuntu 20.04以降（glibc 2.28以降）が必要です。

Claude Codeのアップデート：

* ターミナル：`claude update`。公式インストーラーで入れた場合は、ふだんから自動で更新されます。npm、Homebrew、WinGetで入れた場合は、それぞれ`npm install -g @anthropic-ai/claude-code@latest`、`brew upgrade claude-code`、`winget upgrade Anthropic.ClaudeCode`を使います。
* デスクトップ版：Code画面で動くのはデスクトップアプリ内蔵のClaude Codeで、ターミナルのものとは別なので、それぞれ更新が必要です。macOSは「Claude › Check for Updates」、Windowsは「Help › Check for Updates」を選び、新しいセッションを開いてください。この2つのOSでは、デスクトップアプリは起動するたびにも自動で更新されます。Linuxのデスクトップ版は`sudo apt update && sudo apt upgrade`で更新します。

## Cocoは何をするの？

インストールすると、入力欄の上に帯が1本増えます（設定での名前は「入力欄の上の帯」）。Cocoはそこにあるマグカップの縁にちょこんと座って足をぷらぷらさせながら、一緒にコードを書いたり、退屈しのぎに軽口を言い合ったりしてくれます。

彼の表情や動きは、Claudeの作業状態とリアルタイムに同期します。ファイルを読んでいるときは目で文字を追い、長考しているときは小さな泡をぷくぷく吐き出し、作業が始まると薄型ノートPCを取り出して猛烈にタイピング。作業が終わると、得意げに画面をこちらへ向けて「褒めて！」とアピールしてきます。エラーが出るとシュッと段ボール箱に潜り込み、もしテストが3回連続で落ちようものなら、頭のキーキャップ型リミッターがその場で弾け飛んでダメなコード相手に暴走します（あなたに怒ることはありません）。ターミナルが4〜5分ほど静かになると、フードを目深に引き下げて丸くなり、2本のアホ毛だけを外にゆっくり垂らしながらうたた寝を始めます。

Claudeがリクエストの実行を拒否するたび（HTTP 418）、ティーポットのフタを頭にかぶってむすっとふてくされたりもします。

デスクトップ版には手描きアニメーションが一式入っており、いつでもマウスでつついて遊んだり、頭をなでたりできます。

VS Code拡張機能の帯もデスクトップ版と同じです。ただし「つつく」「なでる」は常に表示されるボタンになり、電池とモバイルバッテリーのアイコンは表示されますが、クリックはできません。

帯に出るふだんのセリフは、すべてあなたのPCの画面上で描かれます。モデルは呼ばず、トークンも使いません。

帯の右側には小さなチャームが2つぶら下がっています。電池が5時間の利用枠、モバイルバッテリーが1週間の利用枠で、目盛りは実際の数値どおりに描かれます。マウスカーソルを合わせると、何時にリセットされるか、今のペースでリセットまで持つかどうかがわかります。コンテキストをどれだけ使ったかも帯に書かれています。

Cocoは暇になるとスリープに入り、眠っているあいだは帯にときどき小さな来客がやってきます。迷子のキーキャップ、紙飛行機、404の小さな幽霊、道に迷ったマウスカーソル……夜にはチカチカと光る小さなUSBライトも灯ります。

デスクトップ版の会話画面では、Cocoが気に入ったコードコメントの横に小さな星のきらめきが付き、テストやビルドが赤から緑に変わると下に小さな花が一輪咲きます。エラー表示や権限の確認は元のままで、勝手にいじることはありません。

ターミナルにはCocoのカラーテーマも用意されています。`/theme`でCocoを選んでみてください。明るい背景にはCoco (light)があります。

## Cocoの痛バッグ

`/coco`と打つと設定が開き、「Cocoの痛バッグ」が出てきます。全部で7ページあります。

* **Coco**：プロフィール、デスクトップペットのCoco Pet、一緒にやること（集中、スキルカード、日記）。ここでClaudeさまに替えたり（ターミナルはCocoのまま）、痛バッグの絵を替えたりもできます。
* **利用枠**：5時間と1週間の利用枠、今回のセッションで使った量、料金表。
* **vibe check**：今回のセッションの戦績。テストが何回落ちたか、何回直したか、Cocoが何回暴走したか、ビルドがいつもより速いか遅いか。画像にして共有もできます。
* **靴下**：全13足の靴下。「はじめての〇〇」を1つ達成するたびに1足もらえて、クリックするとCocoが履き替えます。
* **同人誌**：毎週1冊、あなたとCocoのこの1週間を記録します。
* **付箋**：新しいセッションが始まったとき、前回どこで止まったかを教えてくれます。このPCにだけ保存されます。
* **スイッチ**：すべてのスイッチが用途別にグループ分けされており、トークンを使うものにはすべて印が付いています。

スキルカードは専用のパネルで開きます。「Coco」ページの「スキルカード」を押すか、`/coco cards`と打ってください。手元のスキル、サブエージェント、スラッシュコマンドを、Cocoがカードにしてくれます。スキルとサブエージェントのカードはトレイに入れると、次のプロンプト1回だけに付いていきます。コマンドのカードは「入力欄に書き込む」を押すとコマンドが入力欄に入り、Enterを押すまでは実行されません。カードの図鑑には、それぞれ何回使ったかが残ります。

## 初期設定でオフになっている機能

すべて痛バッグの「スイッチ」ページにあります。あなたの利用枠を使うものはすべて明記されており、初期設定では最新のHaikuを使い、ほかのモデルにも替えられます。

* **DM。** CocoにDMすると、選んだモデルで返事をしてくれます。Cocoから話しかけてくることもあり、セッションをまたいでも前回どこまで話したかを覚えています。自分のAPIキーで支払うこともでき、キーはOS標準のパスワード管理機能に保存されます（macOSはキーチェーン、WindowsはWindows資格情報マネージャー、Linuxはキーリング。Linuxでキーリングがないときは、あなたのアカウントだけが開けるファイル）。WindowsとLinuxでは、自分のキーでの利用をまだ実機で確認していません。
* **セリフ集。** モデルにCocoやClaudeさまの帯のセリフを1セット書いてもらい、このPCに保存します。自分で直すことも、いつでも元に戻すこともできます。
* **返事の口調。** オン：Claudeが作業を終えたあとにCocoがひと言付け足します。リクエストごとに338文字の指示が加わりますが、たいていはプロンプトキャッシュから読まれます。全開：Claudeが最初から最後までCocoのような話し方になります。
* **やさしく説明。** Claudeの直前の返答やあなたが選択した内容を、ワンクリックでわかりやすい平易な言葉に言い換えます。会話自体には影響しません。
* **再チェック。** Claudeがファイルを変更したあと、ワンクリックで別のモデルに変更箇所を見てもらい、気をつけるべき点をリストアップします。
* **わかりやすく。** プログラミングがわからない人でも読んで理解できる返答スタイルにします。
* **上限で確認。** セッションで使う金額の上限を設定しておくと、それを超えたときにCocoがまずClaudeの次のステップを止め、続けるかどうか聞いてくれます。
* **秘密鍵を隠す。** 貼り付けた内容によくある形式の秘密鍵が含まれていると、送信する前にCocoが教えてくれて、ワンクリックで隠せます。
* **キャッシュを保温。** あなたが席を外しているあいだ、Cocoが定期的にキャッシュから会話を読み直すことで、戻ってきてメッセージを送るときの読み込みを安いままに保ちます。実測値：オンのときはキャッシュヒット率99.8%、オフのときは23%。画面ロック、2時間経過、または別の会話を開いた時点で止まります。
* **おとなりの灯り。** ほかのコーディングアシスタントが作業していると、Cocoもそれに気づきます。動いているかどうかと利用枠だけを見ており、中身は見ず、外部への送信もしません。

## プライバシーとコスト

初期状態では、Cocoは画面にいても追加でモデルを呼び出さず、ネットにもつながず、テレメトリも収集しません。Coco自身が、あなたに関する情報をこのPCの外へ送ることはありません。

スイッチページにあるモデルを呼び出す機能は、あなたがオンにしたときだけ利用枠を消費し、どれくらい使うかはすべて画面上に明記されています。権限の確認やセキュリティの警告は一切いじりません。

Cocoがまばたきをするのは待機中だけで、人が本を読むときのように約5秒に1回です。隠れているときや眠っているときはアニメーションを動かしません。システムの「視差効果を減らす」（モーション軽減）をオンにしている場合は、動かずにじっとしています。

Claude Codeのスクリーンリーダーモード（環境変数または設定）をオンにすると、帯は自動的にプレーンテキストになります。起動引数だけを使った場合は、スイッチページの「入力欄の上の帯」で「テキスト」を選んでください。

## 言語

13言語に対応しています。言語の選択では、簡体字中国語は「华文」、繁体字中国語は「國語」と表示されます。ほかの言語はClaudeクライアントの表記と同じです。`/coco lang auto`で自動に戻せます。

## デスクトップペット（Coco Pet）

痛バッグの「Coco」ページで「Coco Petをインストール」を押すか、`/coco companion install`を実行します。Claudeのウィンドウの横にいて、ウィンドウに合わせてついてきます。表情は帯のCocoと同じです。頭をなでたり、ドラッグして連れ回したりでき、サイズは3段階あります。

何かをダウンロードすることはなく、Claudeアプリ本体にも触れず、インストールされたプログラムがネットにつながることは一切ありません。Windows版とLinux版は、私の手元にWindowsとLinuxのPCがないため、まだ実機では確認できていません。

うっかり終了させてしまっても、痛バッグの中で「呼び戻す」をポチッと押せば戻ってきますよ。

## Claudeアイコンの変更

初期設定はオフです。Coco、Claudeさま、Cocoのキーキャップ、Claudeさまの髪飾りの4つから選べます。macOSではClaude.appの中に小さなアイコンファイルを書き込みます。Claudeのアップデート後に元のアイコンへ戻ってしまっても、もう一度押せばまた変更でき、いつでも元に戻せます。Linuxではあなた自身のランチャーファイルだけを変更し、アプリ本体には触れません。

## claude.aiのスキン

「Cocoカラー」はclaude.aiのウェブサイト用のスキンです。色とフォントが変わり、ライトとダークの両方に対応していて、広いウィンドウでは右下にピクセルのCocoが座ります。ブラウザにStylusなどのユーザースタイル拡張機能を入れてから、GitHubでこのリポジトリの`skins/claude-ai/coco.user.css`を開いて「Raw」を押すと、拡張機能がインストールするか聞いてきます。見た目を変えるだけで、ページの内容は読まず、ネットにもつなぎません。いらなくなったら拡張機能で削除してください。実際のclaude.aiではまだ試していません。

## アンインストール

Claudeのアイコンを変更している場合は先に`/coco icon clear`、デスクトップペットを入れている場合は先に`/coco companion uninstall`を実行し、自分のAPIキーを保存した場合は先に痛バッグで削除してください。そのあと以下を実行します。

```bash
claude plugin uninstall coco@coco && claude plugin marketplace remove coco
```

すでにプラグインがない場合：アイコンを元に戻したいときは、FinderでClaude.appを選び、「ファイル › 情報を見る」を開いて左上の小さなアイコンをクリックし、Deleteキーを押します。デスクトップペットを消したいときは、右クリックで終了させてから、以下をゴミ箱に入れてください。

* macOS：`~/Applications/Coco Pet.app`、`~/Library/Application Support/Coco`、`~/Library/Application Support/Coco-presence`
* macOSでは、ターミナルで`security delete-identity -c "Coco Pet Local Signing"`も実行して、Coco Petがログインキーチェーンに作った署名用の証明書を削除してください
* Windows：`%LOCALAPPDATA%\Programs\Coco Pet`、`%APPDATA%\Coco`、`%USERPROFILE%\.local\state\coco`
* Linux：`~/.local/share/coco-pet`、`~/.local/state/coco`、`~/.config/coco-pet`
