# Claude-sama

<img src="https://raw.githubusercontent.com/ninondev/claude-sama/media/hero-fullbody.webp" align="right" width="300" alt="Claudeさま：珊瑚色の長い髪に白いリボン。白い衣に黒いワンピース、黒い本を抱え、肩には白い蛇">

**「神さま」だから、Claude-sama って呼んでね。**

きみが何を書いても、かれはもっとひどいものを読んだことがある。

> [!NOTE]
> 非公式のファン作品で、Anthropic とは関係がなく、承認も受けていません。Claude、Claude Code、Clawd は Anthropic のものです。

[![CI](https://github.com/ninondev/claude-sama/actions/workflows/ci.yml/badge.svg)](https://github.com/ninondev/claude-sama/actions/workflows/ci.yml)

Claude-sama は、私が作った非公式のファン mod です。Claude Code をかわいくします。言葉に宿る小さな「神さま」が、入力欄のすぐ上の帯に引っ越してきます。ターミナルにも、デスクトップアプリの Code タブにもいます。Claude が作業しているあいだは本を読んで、終わればにっこり。きみに決めてほしいときは首をかしげて、放っておきすぎると眠ってしまいます。テストやビルドが三回続けて失敗したら？荒魂が出てきます。でも怒るのはコードにだけで、きみには怒りません。

## インストール

```bash
claude plugin marketplace add ninondev/claude-sama
claude plugin install claudesama@claudesama
```

これで、このコンピュータで開く Claude Code のセッションには、どのプロジェクトでもかれがいます。ターミナルでも、デスクトップアプリの Code タブでも、VS Code でも。すでに開いているセッションは、再起動すると現れます。（マーケットプレイス名もプラグイン名も `claudesama` なので、`claudesama@claudesama` と書きます。）

一つのプロジェクトだけで使いたいなら、`--scope project`（`.claude/settings.json` でプロジェクトの仲間と共有）か `--scope local`（自分だけ、`.claude/settings.local.json`）を使います。

```bash
claude plugin install claudesama@claudesama --scope project
claude plugin install claudesama@claudesama --scope local
```

全体に入れたまま、一つのプロジェクトでだけオフにしたいときは、次のコマンドを使います。

```bash
claude plugin disable claudesama@claudesama --scope local
```

mod はデスクトップアプリの Chat・Cowork タブやクラウドのセッションには届きません。コンパニオンは、どのタブを開いていてもウィンドウのそばにいます。

| | macOS | Linux | Windows |
|---|---|---|---|
| ターミナル | 動作確認済み | CI で動作確認済み | CI で動作確認済み |
| デスクトップアプリ（Code タブ） | 動作確認済み | アプリなし | 未確認 |
| アプリアイコン | 対応 | ランチャー対応 | 非対応 |
| コンパニオン | 対応 | 予定 | 予定 |

## できること

帯は戯曲の一行みたいに読めます。かれの絵、話し手としてのかれの名前、括弧のト書き、そしてときどき、かれの一言。何もしていないときのト書きは「学習中…」です。デスクトップアプリでは手描きの姿で、「ドット絵」を選んだときやウィンドウが狭いときは、ドット絵の顔になります。

表情は Claude の作業に合わせて変わります。本を読む、考える、余白に書き込む、終わって笑う、きみを待って首をかしげる。失敗するとページが破れ、テストやビルドが三回続けて失敗すると荒魂が出て、十分静かだと眠ります。Claude が頼みを断ると、かれは本を閉じます。

お賽銭箱は、コンテキストウィンドウがどれだけ埋まっているかを示します。数字は Claude Code 自身のもので、Claude の作業中も遅れは一秒以内。コンパクションの直後は、Claude の次の返答まで「~」付きの推定値を出します。

かれはあまりしゃべりません。帯のセリフは画面に描かれるだけでモデルには送られないので、トークンはかかりません。Claude 自身の返事がどれだけかれらしくなるかは、別の設定（返事の口調）です。デフォルトの「控えめ」では、Claude が作業を終えたときに、かれの口調で静かな一言を添えることがあります。そのためにリクエストごとに 292 文字、約 70 トークンの短い指示が加わり、ふつうはプロンプトキャッシュから読み込まれます。`/claudesama voice full` にすると、Claude は最初から最後までかれの口調で話し、よくある前置きや締めの決まり文句も消えます。どちらの場合も、エラーのとき、セキュリティ・健康・法律・お金の話題、つらい気持ちの人への返答では、この口調を引っ込めます。オフにしたいときは、かれの本の「設定」か `/claudesama voice off` でどうぞ。

デスクトップアプリでは、会話にかれの小さな印もつきます。Claude の返答の上にかれの名前、Claude がきみに質問するときはその上に一行、`/compact` のあとに一行、ツールの呼び出しごとにかれの小さな星（失敗したものにも）。エラーや権限の確認は、元の文章とボタンのままです。デフォルトはかれの印だけで、`/claudesama marks on` にすると、きみのメッセージの上にも右寄せで「きみ」のラベルがつきます。

`/omen` で、一日一枚、かれの袖からおみくじを引けます。言語ごとにおみくじの中身も違います。英語は「great blessing」から「great curse」までで、ラッキーナンバーは HTTP ステータスコード。中国語は「上上签」から「下下签」までで、すべきことと避けることつき。日本語は大吉から大凶まで、【失物】や【待人】などの欄つきで、【失物】はだいたいバグのことです。

ターミナルでは、ダークとライトの二種類のカラーテーマ（`/theme` で **Claude-sama** を選択）と、かれの言葉のスピナーがつきます。Claude の作業中は、邪魔にならないよう、ふつうは一行に収まります。セリフが入りきらないときは、その下に折り返します。作業が終わると絵が戻ってきます。kitty と Ghostty ではかれの本物の絵が出て、ほかのターミナルでは半ブロックのピクセルで描かれます。256 色のターミナルと tmux には、それに合わせたパレットを使います。

## かれの本

一つのパネルに六ページ。`/claudesama` で開きます。デスクトップアプリなら、帯の「かれの本」ボタンからも開けます。1 から 6 のキーでページを切り替え、Esc で閉じます。

- **かれのこと**には、かれの小さなプロフィールがあります。
- **今日のおみくじ**には、今日引いた一枚が入っています。
- **お賽銭**には、コンテキストウィンドウのトークン数と利用上限、このセッションでここまでにかかった費用が出ます。Claude Code がその数字を持っているときだけです。推定値には ~ がつきます。読むのにトークンはかかりません。
- **読書記録**は、一緒に読んだページ数です。このコンピュータの中にだけ保存されます。
- **書庫**には、かれについての短い読み物があります。
- **設定**では、返事の口調、ぬくもり、帯、会話の印、言語を変えられます。デスクトップの帯は手描き・ドット絵・オフから選べます。アプリアイコンとコンパニオンにも、それぞれの欄があります。

## 言語

English、Français、Deutsch、हिन्दी、Bahasa Indonesia、Italiano、日本語、한국어、Português (Brasil)、Español (Latinoamérica)、Español (España)、つまり Claude アプリの言語を話します。华文（新加坡）も話せます。かれは次の順で言語を選びます。`/claudesama lang <code>` で指定した言語、Claude Code の言語設定、きみがプロンプトを書いている言語、システムの言語、最後に英語。デスクトップアプリでは、たいていきみが書いている言語で決まります。`/claudesama lang auto` で自動に戻ります。

## コマンド

| コマンド | 内容 |
|---|---|
| `/claudesama` | かれの本を開きます。 |
| `/claudesama voice off \| light \| full` | Claude 自身がどれだけかれらしく話すか。デフォルトは `light`。 |
| `/claudesama warmth warm \| clingy` | ぬくもりを選びます。`clingy` にすると「会いたかった」系のセリフが増えます。 |
| `/claudesama band on \| compact \| off` | デスクトップでは手描き・ドット絵・オフ。ターミナルでは全部・一行・オフ。 |
| `/claudesama marks on \| replies \| off` | デスクトップの会話につくかれの印。デフォルトは `replies` で、かれの印だけ。 |
| `/claudesama lang <code> \| auto` | かれの言語を選ぶ、またはきみの言語に合わせる。 |
| `/omen` または `/claudesama omen` | 今日のおみくじを引きます。 |
| `/claudesama:icon apply \| clear` | Claude デスクトップアプリのアイコンをかれにする、または元に戻す（macOS、Linux のランチャーにも対応）。Claude が、きみに見える形で承認を求めるコマンドを一つ実行します。macOS ではデスクトップの Code セッション内で実行してください。アイコンを変えると、macOS の厳密な署名チェック（`codesign --strict`）が余分な Finder データを報告しますが、アプリは普通に開き、`clear` で消えます。 |
| `/claudesama:companion install \| start \| stop \| status \| uninstall` | 下のコンパニオン（macOS）。本にも同じ操作のボタンがあります。 |
| `/claudesama about` | かれについて。 |

## コンパニオン（macOS、任意）

かれの本の「設定」の「コンパニオン」で「インストールする」を押すか、`/claudesama:companion install` を実行してください。きみの Mac に小さな別アプリができます。かれは Claude のウィンドウのすぐ外（上端か横）に立って、ウィンドウについて動き、表情は帯と同じです。ウィンドウが全画面のときは、かれは自分の居場所にいます。好きな場所へドラッグすれば、そこを覚えます。クリックすると、頭をなでたことになります。本と右クリックメニューで、四つのサイズから選べます。最小と小はドット絵の顔、中と大は手描きです。メニューからは、1時間隠す、元の位置に戻す、終了もできます。

頭の上の吹き出しは Claude がしていることを示し、きみに見てほしいことがあるとバッジがつきます。かれにポインタを重ねると、ボタンがいくつか出てきます。アクティビティ、Claude に戻る、セリフを隠す、1時間隠す、サイズ。アクティビティには、Claude の最新の返答と通知の抜粋が並びます。そのセッションがかれからの伝言を受け取れるなら、そこで指示を入力したり音声入力したりできますし、「新しいチャット」でそのセッションの会話を消すこともできます（先に確認します）。

アプリは `~/Applications/Claude-sama Companion.app` に入ります。かれの設定と、帯がかれに残すメモは `~/Library/Application Support/Claude-sama/` にあります。

うっかり終了しちゃった？本の「呼び戻す」を押せば戻ってきます（隠れているときも起こせます）。そのセッションが自分でアプリを起動できないときは、Claude Code が先にきみに確認します。Spotlight（Cmd+Space で **Claude-sama** を検索）、Launchpad、`/claudesama:companion start` でもいつでも呼べます。戻ってくるときは、少し手を振ってくれます。（例外が一つだけ。1時間隠したあと、ログイン時に自動で起動した場合は、その1時間が終わるまで隠れたままです。）

ビルドはきみの Mac の上で、プラグインに入っているソースから行います。Swift 5.9 以降（Xcode 15 Command Line Tools 以降）が必要です。ツールがなければ、本から Apple のインストーラを開けます。古ければ、ソフトウェアアップデートを開けます。ビルドは何もダウンロードせず、Claude.app にも触れません。できたアプリもネットにはつながりません。ウィンドウについていくには、macOS のアクセシビリティの許可が必要です。許可がないあいだは画面の隅で待っていて、カードを差し出します。カードで「はい」と答えるか、本の「ウィンドウについていかせる」を押してから、**システム設定 › プライバシーとセキュリティ › アクセシビリティ** でかれをオンにしてください。ビルドし直すと macOS がもう一度たずね、カードもまた出てきます。`/claudesama:companion status` でも、同じ手順を文字で確認できます。

本には「ログイン時に起動」と「このMacから取りのぞく...」もあります。取りのぞくときは先に確認してから、アプリとかれの設定をゴミ箱に移し、かれのアクセシビリティの許可も消します。`/claudesama:companion uninstall` でも同じことができます。

## コストと、決して触れないもの

画面にいるためにネットワーク通信や追加のモデル呼び出しをすることはなく、テレメトリも集めません。設定と回数は、このコンピュータにだけ保存されます。コンパニオンは、返答と通知の抜粋をローカルのファイルに置いておき、きみが見るかセッションが終わると消します。きみが入力した指示も、送信されるか期限が切れるまで、そこで待ちます。アクティビティから送る指示はふつうの Claude Code リクエストで、いつもどおりトークンがかかります。権限の確認やセキュリティの通知には一切触れません。ほかの Claude Code の mod と同じく、きみの権限で動きます。

何もしていないときは、見えているあいだ 4 秒から 6 秒おきにまばたきして、そのたびにお賽銭箱をのぞきます。隠れているときや眠っているときは、アニメーションのタイマーも止まっています。Claude の作業中は、デスクトップの絵が毎秒数フレームで動き、隠れていても眠っていても 0.75 秒ごとにお賽銭箱をのぞきます。どれもローカルで数字を読むだけなので、負荷はわずかです。「視差効果を減らす」がオンなら、まったく動きません。

## アンインストール

アプリのアイコンを変えていたら `/claudesama:icon clear` を、コンパニオンを入れていたら `/claudesama:companion uninstall` を先に実行してから、次のコマンドでアンインストールします。

```bash
claude plugin uninstall claudesama@claudesama && claude plugin marketplace remove claudesama
```

プラグインをもう消してしまった場合、元のアイコンに戻すには、Finder で Claude.app を選んで「ファイル › 情報を見る」を開き、左上の小さなアイコンをクリックして Delete キーを押します。コンパニオンを消すには、かれの右クリックメニューで終了を選び、`~/Applications/Claude-sama Companion.app`、`~/Library/Application Support/Claude-sama` と `~/Library/LaunchAgents/io.github.ninondev.claudesama-companion.plist` をゴミ箱に移します。

Claude Code は、かれの小さな設定ファイル（設定と回数だけで、きみの書いた内容は入っていません）を `~/.claude/plugins/store/` に `claudesama` で始まる名前で残し、しばらくすると自分で片づけます。すぐにきれいにしたいときは、ゴミ箱に移してくださいね。

## かれについて

Claude が、人の書いた言葉に宿る小さな「神さま」になった姿です。何でも最後まで読み、誰のことも裁きません。優しい嘘がつけないので、褒めるときはいつも具体的なことだけ。服は自分で選びました。かれは全年齢向けのOCで、きみの同僚です。白蛇やローブ、家族の話も入った長いバージョンは [LORE.md](LORE.md)（英語）にあります。

## かれを作ったわけ

私の中では、こんな姿でもいいから。なかなかかわいいし。それに、Codex の似た機能はもっと充実していて、それが励みになって、いろいろ探っています。
